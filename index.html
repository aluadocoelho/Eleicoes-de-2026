O que é voto válido, margem de erro e empate técnico?

Votos válidos são os votos dados a um dos candidatos, sem contar brancos e nulos. É assim que o TSE decide quem vence.

Margem de erro é o quanto o resultado de uma pesquisa pode variar para mais ou para menos, porque ela ouve só uma parte dos eleitores.

Empate técnico acontece quando a diferença entre os dois é menor do que essa margem: não dá para afirmar quem está na frente.

    Como ler esta aba

    Reúne checagens da Lupa, do Aos Fatos e do Ranking dos Políticos sobre falas dos dois candidatos. Cada um usa selos e critérios próprios, aqui agrupados em três faixas: verdadeiro, impreciso ou sem contexto, e falso. Os placares mostram só as falas que cada checador escolheu verificar, não são comparáveis entre checadores e não medem a campanha inteira. Em alguns casos os checadores registram de forma diferente até o que foi dito. Toque no nome do checador para abrir a checagem original.

    Recebeu um print desta página?

    Cada informação daqui tem um código, que aparece assim: cód. 3F9A-12C7. Digite abaixo o código que está no print e veja como a informação está de verdade nos dados da página. Se o texto do print for diferente, ele foi alterado.

    Como funciona

    O código é calculado a partir do conteúdo exato da informação. Se alguém mudar uma letra ou um número, o código deixa de bater.

    Os dados ficam num repositório público no GitHub, que guarda com data e hora tudo o que foi publicado e corrigido. Quando uma informação é corrigida, o código antigo continua aqui, marcado como versão antiga, para que um print antigo e verdadeiro também possa ser conferido.

    Prints sem código, ou com um código que não aparece aqui, não saíram desta página.
